# 接口说明

被测系统提供 10 个 REST 接口，统一响应结构：

```json
{ "code": 0, "message": "success", "data": {} }
```

`code = 0` 成功，`code != 0` 业务失败，原因见 `message`。

## 接口清单

| 方法 | 路径 | 说明 | 需要 token |
|---|---|---|---|
| GET | `/api/health` | 健康检查 | 否 |
| POST | `/api/login` | 登录，获取 token | 否 |
| GET | `/api/books` | 图书列表（搜索 + 分页） | 否 |
| GET | `/api/books/<id>` | 图书详情 | 否 |
| POST | `/api/books` | 新增图书 | 是 |
| PUT | `/api/books/<id>` | 修改图书 | 是 |
| DELETE | `/api/books/<id>` | 删除图书 | 是 |
| POST | `/api/books/<id>/borrow` | 借书 | 是 |
| POST | `/api/books/<id>/return` | 还书 | 是 |
| GET | `/api/borrows` | 我的借阅记录 | 是 |

## 业务规则

1. **登录**：用户名与密码必须都正确才返回 token。
2. **鉴权**：除「登录」「图书查询」外，所有写操作必须携带有效 token；缺失或无效返回 HTTP 401。
3. **图书字段**：`title` 必填且不能是空白串，长度 ≤ 100；`author`、`isbn` 可为空；`price` 精确到分（两位小数）；`stock` 为非负整数。
4. **借阅数量**：单次借阅 1~3 本，超出应被拒绝。
5. **库存约束**：`stock=0` 不可借出；借出数量不得超过当前库存；库存不允许为负。
6. **重复借阅**：同一账号对同一本书，未归还前不能重复借阅。
7. **归还**：只能归还自己借的书；归还数量不得超过实际借出数量；库存不允许虚增。
8. **借期**：1 个月，`due_time = borrow_time + 1 个月`。
9. **时间格式**：统一为 `YYYY/MM/DD HH:mm:ss`。
10. **搜索**：`keyword` 匹配书名与作者，忽略大小写与首尾空格；空关键字返回全部。
11. **分页**：`page` 从 1 开始，`size` 为每页条数；`page` 超出总页数返回空列表；非法参数应返回「参数错误」而不是崩溃。
12. **错误处理**：业务失败返回 `code != 0` 并给出可读原因；服务端异常应返回 5xx，不得把内部堆栈、文件路径等细节返回给调用方。

> 本仓库文档中的「第 N 条」均指上述业务规则编号。
