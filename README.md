# 图书借阅系统 · 接口测试与自动化实践

以 10 个 REST 接口的图书借阅系统为被测对象，完成接口功能、鉴权、参数校验与异常路径测试，并用 pytest 搭建一套可重复执行的回归用例集。

| 指标 | 数值 |
|---|---|
| 被测接口 | 10 个 |
| 自动化用例 | 51 条 |
| 执行失败 | 27 条 |
| 缺陷单 | 32 条 |

## 快速开始

被测系统需运行在 `http://127.0.0.1:5000`（不在本仓库内）。

```bash
pip install -r requirements.txt
pytest -v
pytest --junitxml=report.xml
```

Windows 下可双击 `运行测试.cmd`。

## 执行结果

最近一次全量执行：**51 条用例，24 通过、27 失败**。

| 类别 | 条数 | 现象 |
|---|---|---|
| 鉴权缺失 | 2 | 假 token 可读借阅记录 |
| 鉴权顺序错误 | 1 | 无 token 删书先返回"图书不存在" |
| 错误 HTTP 方法未处理 | 4 | PUT/DELETE/POST/GET 误用返回 200 + 堆栈 |
| 非法路径 id 异常被吞 | 3 | 返回 200 + code=0 + 完整堆栈 |
| 分页参数未校验 | 8 | page/size 非法值照常返回数据 |
| 图书标题未校验 | 3 | 空/空白/超长标题创建成功 |
| 借阅数量未校验 | 4 | quantity=0/-1/abc 借书成功 |
| 零库存可借 | 1 | stock=0 仍借出成功 |
| 归还数量未校验 | 1 | 借 1 还 2 成功，库存虚增 |

完整报告见 [report.xml](report.xml)，分类说明见 [docs/03-测试结果.md](docs/03-测试结果.md)。
